# Vickson's Store | Eatery & Catering

**Live site:** https://c20245005delachina-prog.github.io/Vickson's Store/

## About

Vickson's Store is a website for a Filipino carinderia and catering business. It introduces the store, displays Filipino food and prices, describes catering services, and provides contact information for customers.

## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |
|---|---|---|---|
| Dominant | 60% | `#FFF7ED` | Page background |
| Secondary | 30% | `#FFFFFF` | Cards, sections, navigation |
| Accent | 10% | `#EA580C` | Buttons, links, highlights |

### Visual style

**Style chosen:**  Minimalism
**Why I chose it:** I chose minimalism to make the website simple, clean, and easy for customers to navigate.

### Contrast check

Body text color vs. background color: `#292524` on `#FFF7ED`
Contrast ratio: Approximately 12.5 : 1 (needs to be at least 4.5 : 1)
Tool used: WebAIM Contrast Checker
